# 对标账号公开数据自动采集系统：项目规划书

## 1. 项目定位

本项目是一个内部使用的“对标账号公开数据自动采集系统”。

它不是手动台账，也不是视频下载工具，而是用于团队持续观察抖音、视频号对标账号的公开数据变化。

核心目标：

> 添加对标账号后，系统按周期自动采集公开可见数据，并生成每周变化汇总，帮助团队观察账号增长和视频表现。

## 2. 使用场景

团队成员需要长期观察一批视频号、抖音对标账号，包括：

- 哪些账号粉丝增长快
- 哪些视频点赞、评论、收藏增长快
- 哪些账号近期内容表现变好
- 哪些视频值得拆解复盘
- 每周对标账号整体变化情况

系统主要服务于内容运营、账号运营、管理者复盘，不用于采集隐私数据或下载内容。

## 3. 第一版产品目标

第一版只解决一个核心问题：

> 用户配置账号，系统自动按周期采集公开指标，并按周汇总新增变化。

第一版完成后，用户应该可以：

- 添加抖音/视频号对标账号
- 设置每个账号的采集周期
- 点击立即更新
- 查看账号粉丝量
- 查看公开视频点赞量、评论数、收藏数
- 查看每周新增变化
- 知道哪些数据是“平台未公开”
- 知道哪些任务是“采集失败”
- 对账号或视频补充标签和备注

## 4. 第一版 MVP 范围

第一版包含以下功能：

- 支持平台：抖音、视频号
- 对标账号管理：新增、编辑、停用、归档
- 账号级采集周期配置：每日采集、每周采集、仅手动采集
- 默认采集周期：每日采集
- 支持“立即更新”
- 自动采集公开可见数据
- 记录账号粉丝量
- 记录公开视频指标：点赞量、评论数、收藏数
- 每周计算新增变化：粉丝新增、点赞新增、评论新增、收藏新增
- 提供账号列表、账号详情、视频数据、采集任务、周汇总页面
- 支持人工补充标签和备注
- 明确展示“平台未公开”“采集失败”“数据不足”

## 5. 不做的内容

第一版明确不做：

- 不采集非公开数据
- 不绕过登录、验证码、风控、权限限制
- 不采集评论正文
- 不采集评论用户信息
- 不采集粉丝列表
- 不采集私信
- 不下载视频
- 不做分钟级/小时级高频监控
- 不做复杂 BI 看板
- 不做 AI 自动选题分析
- 不做移动端 App
- 不承诺所有平台字段都一定能采到

原则是：

> 页面公开展示什么，系统才采集什么；平台不公开，就不采集。

## 6. 用户角色

管理员负责系统配置、账号管理、权限管理、合规边界确认。

运营成员负责添加对标账号、设置采集周期、查看结果、补充标签和备注。

分析查看者只查看账号变化、视频表现和周汇总，不修改核心配置。

第一版可以先不做复杂权限，默认本机内部团队使用。

## 7. 核心流程

### 添加对标账号

1. 进入账号管理页。
2. 选择平台：抖音 / 视频号。
3. 填写账号名称。
4. 填写账号主页链接。
5. 设置分类、标签、关注原因。
6. 设置采集周期，默认每日。
7. 保存账号。
8. 系统创建采集计划。
9. 用户可以点击“立即更新”触发第一次采集。

### 自动采集

1. 系统按账号采集周期生成任务。
2. 到达采集时间后，访问公开页面。
3. 采集公开可见指标。
4. 成功数据写入数据库。
5. 不公开字段标记为“平台未公开”。
6. 页面异常、访问失败等记录为“采集失败”。
7. 不覆盖历史成功数据。

### 查看账号变化

1. 用户进入账号详情页。
2. 查看最新粉丝量。
3. 查看粉丝变化趋势。
4. 查看该账号公开视频列表。
5. 查看视频点赞、评论、收藏变化。
6. 补充标签、备注或标记重点视频。

### 查看周汇总

1. 用户进入周汇总页。
2. 选择时间范围、平台、账号分类。
3. 查看每个账号本周变化。
4. 查看粉丝新增、点赞新增、评论新增、收藏新增。
5. 标记值得复盘的账号或视频。

## 8. 页面模块

首页 / 概览页显示本周账号总数、本周已采集账号数、本周采集失败账号数、粉丝增长 Top 账号、视频互动增长 Top 账号、最近一次采集状态。

对标账号管理页支持账号列表、新增账号、编辑账号、停用账号、归档账号、设置采集周期、平台筛选、分类筛选、状态筛选、立即更新。

账号详情页显示账号基础信息、所属平台、采集周期、最新粉丝量、最近采集时间、粉丝变化趋势、公开视频列表、视频指标变化、采集历史、标签和备注。

视频数据页显示所属账号、平台、视频链接、发布时间、标题或摘要、点赞量、评论数、收藏数、指标采集时间、指标公开状态、标签和备注。

采集任务页显示任务列表、任务状态、最近执行时间、下次执行时间、成功 / 部分成功 / 失败、失败原因、重试入口、立即更新记录。

周汇总页按周查看账号变化、粉丝新增、视频点赞新增、评论新增、收藏新增、平台筛选、账号分类筛选、数据不足说明、平台未公开说明。

## 9. 采集指标

账号级指标：

- 平台
- 账号名称
- 账号主页链接
- 粉丝量
- 最近采集时间
- 最近采集状态
- 每周新增粉丝量

可选公开字段：

- 账号简介
- 头像链接
- 作品数量
- 总获赞量

视频级指标：

- 视频链接
- 标题或文案摘要
- 发布时间，如果公开
- 点赞量
- 评论数
- 收藏数，如果公开
- 首次发现时间
- 最近采集时间
- 每周点赞新增
- 每周评论新增
- 每周收藏新增

## 10. 数据字段

账号表：账号 ID、平台、账号名称、账号主页链接、平台公开账号 ID、分类、标签、关注原因、内部负责人、采集周期、状态、最新粉丝量、最近采集时间、最近采集状态、备注、创建时间、更新时间。

账号快照表：快照 ID、账号 ID、采集时间、粉丝量、粉丝量状态、原始文本、来源链接、采集任务 ID。

视频表：视频 ID、账号 ID、平台、视频链接、平台视频 ID、标题或摘要、发布时间、封面链接、首次发现时间、最近更新时间。

视频快照表：快照 ID、视频 ID、采集时间、点赞量、评论数、收藏数、点赞状态、评论状态、收藏状态、原始指标文本、采集任务 ID。

采集任务表：任务 ID、账号 ID、平台、任务类型、采集周期、计划执行时间、实际开始时间、完成时间、状态、成功采集字段、平台未公开字段、失败原因、重试次数、触发来源。

周汇总表：周汇总 ID、账号 ID、平台、周开始日期、周结束日期、周初粉丝量、周末粉丝量、粉丝新增、本周新增公开视频数、点赞新增、评论新增、收藏新增、收藏数汇总状态、未公开指标说明、汇总生成时间、人工备注。

## 11. 采集周期规则

每个账号独立配置采集周期：

- 每日采集：每天执行一次
- 每周采集：每周固定一天执行一次
- 仅手动采集：不自动执行，只响应“立即更新”

默认值：新增账号默认每日采集。

规则：

- “立即更新”不改变原定周期。
- 暂停账号不自动采集。
- 归档账号不自动采集。
- 同一个账号同一时间只允许一个采集任务。
- 连续失败的账号要显示异常状态。
- 失败后默认最多重试 1 次。
- 遇到验证码、登录限制、权限限制，不自动重试。

## 12. 平台未公开数据处理规则

系统必须区分三种状态：

- 已采集：页面公开展示该字段，系统成功读取并保存。
- 平台未公开：页面可以正常访问，但该字段没有公开展示。数值为空，状态标记为“平台未公开”，不算系统失败，周汇总不按 0 计算。
- 采集失败：页面无法访问、网络失败、页面结构变化、触发限制等。记录失败原因，不覆盖上一次成功数据，写入采集日志，页面显示失败状态。

## 13. 周汇总规则

每周生成一次变化汇总。

建议默认：

- 周起始日：周一
- 周汇总生成时间：每周一上午
- 计算方式：本周最后一次有效采集 - 本周第一次有效采集

如果某个账号每周只采集一次，则显示当前采集值与上一次有效采集值的变化。

如果缺少有效数据，则标记“数据不足”，不强行推断，不把缺失值当作 0。

## 14. 分阶段开发计划

阶段 1：账号管理和基础框架。本地 Web 基础页面、SQLite 数据库、账号新增编辑停用归档、平台分类标签备注、采集周期配置、立即更新入口、合规提示。

阶段 2：采集任务和数据入库。采集任务表、采集日志、每日 / 每周 / 手动采集规则、账号粉丝快照、视频指标快照、平台未公开状态、采集失败状态。

阶段 3：抖音/视频号采集器。公开页面采集器、通用采集结果格式、数字格式标准化、原始文本保存、失败原因记录。

阶段 4：结果查看。账号详情页、视频数据页、粉丝变化、点赞/评论/收藏变化、采集历史、异常状态提示、标签和备注。

阶段 5：周汇总。周汇总计算、粉丝新增、点赞新增、评论新增、收藏新增、数据不足说明、平台未公开说明、平台和分类筛选。

阶段 6：体验和安全完善。失败重试、操作日志、字段口径说明、CSV/Excel 导出、SQLite 备份、本地页面访问保护。

## 15. 第一版验收标准

第一版完成时，至少要满足：

- 可以添加抖音、视频号对标账号
- 每个账号可以设置每日、每周、仅手动采集
- 默认采集周期为每日
- 可以点击“立即更新”
- 系统能生成采集任务
- 采集任务有状态和日志
- 成功后能保存账号粉丝量快照
- 成功后能保存视频点赞、评论、收藏快照
- 收藏数不公开时显示“平台未公开”
- 采集失败时不覆盖历史成功数据
- 周汇总能展示粉丝、点赞、评论、收藏新增
- 数据不足时显示“数据不足”
- 不采集评论正文、评论用户、粉丝列表、私信
- 不下载视频
- 不绕过登录、验证码、风控、权限限制
- 本地数据可保存、备份和导出

## 16. 当前默认口径

- 最近视频数量：20 条
- 每日采集时间：上午 9 点
- 周起始日：周一
- 第一版仅本机访问
- 失败自动重试 1 次
- 字段不可见显示“平台未公开”
- 数据不足显示“数据不足”
- 支持 CSV/Excel 导出
- 支持账号标签/分组
- 抖音和视频号都纳入第一版，但允许视频号字段不完整
